# hello-world

## Overview / 概要

`hello-world` は、HTMLの基本構造とGitHubでのリポジトリ管理を学ぶための小さな学習用プロジェクトです。

HTMLファイルの最小構成を確認しながら、見出し、本文、ブラウザ表示、GitHub上でのREADME作成を練習することを目的としています。

## Purpose / 学習目的

- HTMLドキュメントの基本構造を理解する
- `Hello, world!` をブラウザに表示する流れを確認する
- GitHubでREADMEを整理して、プロジェクト内容を伝えられるようにする
- 小さなコードでも目的、使い方、学んだことを記録する習慣をつける

## Tech Stack / 技術スタック

| Category | Technology |
|----------|------------|
| Markup | HTML |
| Version Control | Git / GitHub |
| Documentation | Markdown |

## Sample Code / サンプルコード

```html
<!DOCTYPE html>
<html lang="ja">
  <head>
    <meta charset="UTF-8">
    <title>Hello World</title>
  </head>
  <body>
    <h1>Hello, world!</h1>
  </body>
</html>
```

## Usage / 確認方法

このREADME内のサンプルコードを `index.html` として保存し、ブラウザで開くと `Hello, world!` が表示されます。

```bash
open index.html
```

macOS以外の環境では、作成した `index.html` をブラウザにドラッグ&ドロップして確認できます。

## What I Learned / 学んだこと

- HTMLは `<!DOCTYPE html>`、`html`、`head`、`body` の基本構造で構成される
- `meta charset="UTF-8"` を指定することで日本語を正しく表示しやすくなる
- READMEには、概要、目的、使い方、技術スタックを書くと内容が伝わりやすくなる
- 小さな学習リポジトリでも、後から見返せる記録として整理できる
